<summary>참여 범위 · 자료 출처</summary>

- **YAMON:** 2026년 7월 초~중순, 약 2주. 해당 UI 디자인·화면 구현 참여율 100%. 서비스 전체 개발 참여율을 뜻하지 않습니다.
- **팡팡팡:** 웹 이미지는 기존 저장된 로그인 상태의 실제 화면입니다. 사용자 요청에 따라 사용했으며, 현재 시점에 로그인·진단 기능을 새로 실행한 결과는 아닙니다. 앱 이미지는 기존 공개 자료입니다.
- **팡팡팡·회의 에이전트:** 화면과 코드 구성을 바탕으로 소개합니다. 개인 담당 기능·PR·기여율은 추가 확인이 필요합니다. 이번 소개가 현재 서비스 동작이나 외부 계정 연동을 새로 검증했다는 뜻은 아닙니다.
- **기술 표기 기준:** 프로젝트의 의존성·코드 import·배포 구성과 문서를 확인했습니다. Route 53은 팡팡팡 공개 README의 배포 구성 기준입니다. OpenAI는 회의 에이전트 코드에서 확인됐으며, 팡팡팡은 Gemini 사용 코드가 확인돼 구분했습니다. 프로젝트 기술 구성이 각 기술의 단독 구현이나 숙련도 등급을 뜻하지 않습니다.
- 회사·고객 내부 코드와 운영 데이터는 포함하지 않습니다.
